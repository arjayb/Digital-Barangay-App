Digital Barangay App

A digital front desk for Barangay San Isidro.

The project

A better barangay front desk

Digital Barangay connects residents and barangay staff through one online workflow. Residents can create accounts, request documents, report non-emergency concerns and track updates. Staff can review submissions and manage their status from a protected admin dashboard.

What residents can do

  • Create and manage a resident account.
  • Submit document requests and receive a tracking number.
  • Report community concerns with location and description.
  • Track request and concern status from the resident dashboard.
  • View published barangay officials and notices.

What staff can do

  • View live resident activity.
  • Review document requests.
  • Move requests through pending, review, approval and completion.
  • Review concerns and update their response status.
  • Operate through protected admin authentication.

Full-stack architecture

This is a real full-stack application rather than a static website. The frontend is published through GitHub Pages, the Express API runs on Render, Prisma handles database access, and PostgreSQL is hosted by Neon.
